# Watch 5 本地计时 ⇄ 手机 Wi-Fi 实时同步（协议 2）

## 数据方向

手表是独立计时器，不是手机遥控器；手机是历史与统计的权威端。

1. 手表开始/停止：先在手表 `timetrak-device-v1.db` 一个事务里写入会话和待发操作（outbox），不等网络。
2. 手表联网后按顺序 `POST /v2/ops` 上报 `session_start` / `session_end` / `settings_put`。每条操作有不变的 `op_id`，会话有不变的 `session_id`，重放不会重复。
3. 手机 `LanOperationApplier` 通过原版 interactor 写入 Room：
   - 手表开始 → 手机出现运行中计时（通知栏、计时页、小部件同步刷新），开始时间用手表时间；
   - 手表结束 → 手机生成完成记录（记录 ID 由 `session_id` 确定），短记录按用户“忽略短记录”设置处理；
   - 手机已先停止 → 返回 `superseded`，以手机为准；
   - 手机同一活动已在计时 → 合并为同一计时（以手机开始时间为准）；
   - 离线期间整段完成的会话 → 直接导入完成记录。
4. 手表在前台时每 3 秒 `GET /v2/state?known=<rev>`；`rev` 是手机快照内容哈希，未变化时只返回 `unchanged`。快照包含活动目录（卡片顺序、颜色、隐藏）、分类、运行中计时和“允许多任务”设置。
5. 手机上开始的计时会出现在手表上，手表可直接停止；手机上停止的计时，手表下一次拉取时自动结束本地会话。
6. 写入 Room 后唤醒 `NativeCloudBridge`，如已配置云端则继续上传；手表会话 UUID 会被沿用，同一会话在云端不会出现两份。

## 安全

- 配对密钥 128 位，只在手机页面显示，不在网络上传输。
- 每个请求/响应带 `X-TT-Ts`、`X-TT-Nonce`、`X-TT-Sig`（HMAC-SHA256，覆盖方法、路径、时间、随机数和正文哈希），时间窗 ±5 分钟，随机数防重放；手表时钟偏差会按手机时间自动校正一次。
- 手机只接受私有网段来源；**通信仍是未加密 HTTP**，只在自己的 Wi-Fi 或手机热点使用，切勿做公网端口映射。

## 运行方式

- 手机：设置 → “TimeTrak · 手表 Wi-Fi 直连” → 开启接收。接收端是带常驻通知的前台服务（类型 connectedDevice），离开页面继续工作；通知栏可停止；开启状态在应用重启后恢复。
- 手表：设置 → “Wi-Fi 直连手机”，填写手机页面显示的 IP 和配对密钥（可带空格）。
- 手表设置中可开启“按分类分组显示”，按手机分类顺序分组，未分类活动放在最后。
- 只配置云端、不配对 Wi-Fi 的手表仍走原有云同步路径。

## 已知限制

- 暂不支持暂停/恢复（STT 记录为连续区间）。
- 手表统计只覆盖手表记录或看到的计时；完整历史在手机。
- 标签选择、备注暂不在手表端同步。
- 系统省电策略可能延后后台补传；手表回到前台会立即同步。
- 手表卸载或清除数据会删除尚未同步的记录。
