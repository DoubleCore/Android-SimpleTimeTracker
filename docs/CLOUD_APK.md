# 手机与 Xiaomi Watch 5 云同步安装包

- STT-Phone-Cloud.apk：原版手机完整应用，原计时、历史、统计、标签、导出界面保留；增加真实数据库云同步。
- STT-Watch5-Cloud.apk：原版手表界面，活动、开始/停止、重复上次计时与每日统计改为 HTTPS 云通信，不需要 Google Play 服务。
- 两端进入云同步连接设置，可填写自己的兼容服务器地址；当前默认 https://stt-cloud-production.up.railway.app ，填写相同 STT_TOKEN。密钥从 Railway 项目 stt-cloud 的 Variables 复制。
- 手机从顶部云同步状态进入设置，手表首次打开进入设置，后续从设置页进入。
- 手机连接后会上传该安装包本地的已有活动及计时历史，并下载手表记录进入原版历史/统计。其他包名的旧应用需先导出再在此版本导入，不会读取其他应用私有数据。
- 同步范围：活动名称/图标/颜色/备注/归档状态，计时开始、停止、记录时间、记录备注、记录删除。标签、分类、目标、番茄钟与偏好设置保留手机本地功能，但此版本不做跨端同步；手表按活动显示每日统计。
- 程序运行时每约 2 秒尝试同步；Android 杀进程或限制后台网络后，下次打开应用会继续补传。不承诺系统杀进程后仍即时同步。
- 手机离线数据留在原数据库；手表操作先写本地 SQLite 队列。网络恢复后补传，服务器 ACK 在磁盘事务提交之后发出。
- 同一记录的离线编辑按服务器接收顺序合并。已结束的记录不能被旧的运行状态重新开启；冲突在同步详情中保留待处理操作。
- 这是可安装的完整功能开发签名构建，非应用商店发行签名。若旧开发包签名不同，先导出数据，切勿为覆盖安装直接清除数据。

- 本次交付跳过 Railway 部署。原生手机记录上传要求服务器 `/v1/health` 声明 `native_records_v1`；旧服务器下操作会保留在待同步队列，不能视为双向同步已完成。
