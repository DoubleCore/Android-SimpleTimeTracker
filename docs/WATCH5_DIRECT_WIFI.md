# Watch 5 国行：手机局域网直连 + 手机 HTTPS 云上传（并行）

## 已采用的单一数据源

- **手机**：原版 STT Room 数据库是主要记录库。手机本来的计时、历史、标签、统计不替换。
- **Watch 5**：选择 `Wi-Fi直连手机` 时，从手机读取原生活动/运行中记录/最近100条历史；发送开始/停止操作，等待手机写入并确认，然后重新拉取状态。
- **手机云同步**：已有 `NativeCloudBridge` 在应用进程运行时扫描原生 Room 增量，写入手机云同步 SQLite outbox，经原有 `CloudSync` 上传到 HTTPS 服务器。手机的 LAN 操作同样写入 Room，因此能被桥接到云端。不需要手表拥有云凭据。
- **其他设备**：使用已有云同步协议；云服务与手机直连是两条独立网络链路。手机无需等待云端响应才向手表确认 LAN 操作。
- **断网**：云不可用但 LAN 可用仍可操作手表计时；LAN 不可用时直连操作会失败（不会谎报成功、不会静默改用云）。保留手表现有云模式作为手动替代选项。

## 快速安装和直连（前台 M1/M2）

1. 在该分支 GitHub Actions **Full phone and Watch APK** 成功运行页面下载 artifact `STT-Phone-Watch5-Full-APK`；确认 COMMIT.txt 和 SHA256SUMS.txt。
2. 安装 `STT-Phone-Cloud.apk` 到手机，`STT-Watch5-Cloud.apk` 到手表。原 debug 签名/包名不同时请先备份数据，不要直接卸载含数据的旧版。两端为独立设备。
3. 手机在主界面点 `Wi-Fi直连手表（手机服务端）`，选择与手表互通的私有 IPv4，按 `启动服务：IP:8765`。页面出现 `正在监听`；记录该 IP 和页面上的配对密钥（不要发送截图或公开密钥）。
4. 手表进入 `Wi-Fi直连手机` 设置页，输入手机的 IPv4（不含 http:// 或端口）和32位密钥；点 `保存并连接`。首次安装会引导直连设置；已经配置云端的手表从设置页切换。
5. 返回手表主页：活动列表与手机一致；从手表开始/停止一个活动；查看手机历史、计时状态和统计。手机正在运行的活动在手表中也能看到。
6. 手机点原顶部 `云同步` 设置，输入已部署兼容云服务器的 HTTPS 地址与 STT_TOKEN。若此前已有有效配置无需重复配置。云同步桥定期同步 Room，状态仍在顶部可见。只向用户可信的 HTTPS 服务器上传真实历史数据。
7. 关闭云端网络后仍能 LAN 操作；关闭手机直连页后则停止局域网服务器（当前前台版本刻意如此）。

## 编译

在仓库根目录，JDK 21 + Android SDK 34/35：

```bash
bash ./gradlew :app:assembleBaseDebug :wear:assembleDebug --no-daemon
```

APK 输出目录：
- `app/build/outputs/apk/base/debug/`
- `wear/build/outputs/apk/debug/`

专用 CI 工作流 `.github/workflows/cloud-sync.yml` 构建并打包两端 APK。

## 当前边界和安全

- 局域网仅支持私有 IPv4，端口 8765；手机必须保持直连 Activity 可见且进程存活，**目前没有前台服务持续保活**。
- 手表局域网客户端不排队离线指令；请求不成功时展示错误，而不是认定成功。
- 手机 HTTP 服务以32位随机配对密钥验证请求，只绑定选择的私有 IPv4，并限制请求和并发。**局域网 HTTP 未加密，仅能用于本人控制、可信的 Wi-Fi 或热点**；不得直接暴露到公网、映射公网端口或经不受信任 Wi-Fi 使用。云上传使用独立的 HTTPS 和云端密钥。
- 局域网客户端模式不自动退回云模式（避免网络切换时操作顺序不一致）；手表原云模式仍可通过清除 LAN 配置手动使用。
- 不保证在息屏、Android 系统冻结或手机离开直连页后实时在线。完整后台版本另需前台服务、电池管理和异常断线恢复。
- 手机云同步要求远端实现 `/v1/health` 中的 `native_records_v1` 协议；只存在源码或 CI 通过并不等于已在实际服务器可用。
- 仅支持手机现有活动/记录的直连列表和开始/停止。手表不编辑标签和备注；云端是否成功必须以服务器 ACK、手机同步状态和数据下载校验为准。

## 接受条件

- [ ] 构建同时生成原生手机和原生手表 APK，且都可在对应真机启动
- [ ] 同 Wi-Fi 后手表显示手机原生活动
- [ ] 手表开始计时，在手机原版运行中列表出现一次（而不是独立的云页面）
- [ ] 手表停止同一会话，在手机原版历史出现一次；重复停止不增加记录
- [ ] 手机本地创建/修改活动，手表刷新后显示
- [ ] 手机配置云端后，LAN 生成记录成功经手机 HTTPS 上传；另一个云客户端能拉到同一 ID 的单条记录
- [ ] 云断网时 LAN 可继续写手机 Room，云恢复后补传
- [ ] 手机直连页面关闭/错误密钥时手表明确失败
- [ ] 不存在公网监听或匿名写入口
