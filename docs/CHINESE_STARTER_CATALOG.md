# TimeTrak 固定中文活动与标签（v1）

手机和小米 Watch 5 的时间记录使用中文名称。无需先在手机上手工创建 7 个活动和 27 个标签。

## 中文预置目录

| 活动（手表计时按钮） | 只对这个活动开放的普通标签 |
| --- | --- |
| 科研 | 论文阅读、实验复现、模型训练、消融实验、结果分析 |
| 编程 | 功能开发、程序调试、代码审查、系统部署 |
| 学习 | 理论学习、课程学习、资料整理、知识复习 |
| 项目 | 需求分析、方案设计、文档编写、项目沟通 |
| 会议 | 学术会议、团队讨论、项目汇报 |
| 生活 | 饮食、家务、出行、日常事务 |
| 休息 | 午休、娱乐、放松 |

共 7 个活动 / 27 个标签。活动图标使用汉字单字：研、码、学、项、会、生、休。颜色使用原 STT 调色板的稳定颜色 ID。所有标签都是无需填写数字的普通标签，满足手机 AI 自动分类的白名单筛选。

## 实际数据流程

1. 新安装首次打开手机 STT：仅当原生 Room 中活动和标签都为空时，自动初始化该目录。
2. 手机连接 Wi-Fi 热点/局域网，Watch 5 初次通过 `/v1/state` 获取中文活动目录并缓存。手表无需自己建标签。
3. Watch 5 **独立开始和结束**活动。离线也先存本地 SQLite，联网后将**完整结束记录**同步手机原版 Room。
4. 手机收到带 Description 的新记录后，使用用户单独配置的付费大模型 API **由手机直接进行分类**：`GetSelectableTagsInteractor.execute(typeId)` 仅提供此活动允许的已有中文标签候选；结果写入手机原版 Room。
5. 手机将计时数据和 Description 按原有路径上传云端，**服务器不会执行 AI 分类**。当前云同步尚未完整支持标签关联的云端备份，需要后续完善。

## 已有数据的安全策略

- **新安装空数据自动导入**；已经有活动或标签的用户，不会偷偷覆盖原数据库、自动翻译名称或替换原有标签 ID。
- 旧用户可在首页点击「中文活动与标签（固定预置）」→「导入中文预置（保留已有数据）」。
- 按名称复用已存在的同名中文活动/标签，补齐缺少的数据和关联；重复点击不会无限新增副本。
- 已有英文标签不会被强行删除或自动翻译（避免破坏历史关联）；可以自行在 STT 的标签管理中安全重命名。
- 预置只是首次种子，不是永久不可修改的硬编码 UI；以后需要改中文名称时可以直接通过 STT 原生标签管理修改。程序不会在每次启动时把修改强行改回默认值。
- 初始化进程被中断时，状态在手机本地标记为 started，下一次可在保留原有数据情况下续写缺少项。
- 无需手动配置每一个中文标签，**付费 AI Key 仍需用户在手机单独配置一次**。

## 源码及验收

- `app/src/main/java/com/example/util/simpletimetracker/catalog/ChineseStarterCatalog.kt`：7×27 预置、原生 Room 操作、幂等关联与首次启动策略。
- `app/src/main/java/com/example/util/simpletimetracker/catalog/ChineseCatalogActivity.kt`：旧用户预览/安全导入界面。
- `app/src/main/java/com/example/util/simpletimetracker/ui/MainActivity.kt`：首次打开初始化、完成后重新渲染活动界面。
- `app/src/main/java/com/example/util/simpletimetracker/ai/PhoneAiTagger.kt`：消费本地活动-标签范围，调用用户付费 AI API 自动匹配。

验收项目：
- [ ] 纯新装首次打开立即看到中文 7 活动，数据库只有 27 个不同中文标签和 27 条目标关联。
- [ ] 重启手机/应用 3 次不出现重名记录或重复关联。
- [ ] 原生 STT 已有历史/英文标签时，打开应用不改变历史；手动导入后 7/27 目录齐全，旧数据仍保留。
- [ ] 手机新建/手表同步的科研记录描述，AI 候选集只包含科研的 5 个中文标签（其他活动同理）。
- [ ] 手表连接手机局域网能缓存并显示中文活动名，独立计时并补传原始时间记录。
- [ ] 中文活动在云端按正确活动 UUID 同步；中文标签云备份需独立验收。
- [ ] 退出页面、断网、锁屏不会造成手表本地时间记录丢失（但手机 LAN 接收服务的后台保活仍须改进）。

截至提交仅代码实现，GitHub CI 构建与手机 + Watch 5 真机验收需要以实际结果为准。
